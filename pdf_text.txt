 1. ABSTRACT  
This project presents the development of an advanced object detection system 
leveraging Flask and YOLO (You Only Look Once). The system is designed 
to efficiently detect and classify objects in images or live video streams, 
providing real -time analysis with high accuracy and speed. YOLO's single -
shot detection mechanism makes it highly effective for real -world 
applications where rapid processing is essential.  
The implementation involves a user -friendly web interface where users can 
upload images or access live camera feeds for object recognition. The detected 
objects are highlighted with bounding boxes and labelled  with confidence 
scores, ensuring precise ident ification. This system finds applications in 
various domains, including security surveillance, autonomous vehicles, retail 
analytics, and smart traffic management.  
By integrating Flask as the web framework, the system ensures seamless 
deployment and access ibility through a web -based interface. The combination 
of YOLO’s deep learning capabilities and Flask’s lightweight architecture 
makes this solution robust, scalable, and suitable for diverse AI -driven 
automation tasks.

  6. EXISTING SYSTEM  
 
Haar Cascades (OpenCV -based):  
Haar  cascades use predefined features for object detection but suffer from 
high false positives and poor performance with complex objects and varying 
conditions. While fast, they lack robustness and accuracy, making them 
unsuitable for real -time applications.  
 
RCNN and Variants (Fast RCNN, Faster RCNN):  
RCNN introduced deep learning for object detection but is computationally 
expensive and slow. Fast RCNN improved speed using Region of Interest 
(RoI) pooling, but remained inefficient for real -time use. Faster R CNN 
optimized this further with a Region Proposal Network (RPN), increasing 
accuracy but still being too slow for real -time applications.  
 
SSD (Single Shot MultiBox Detector):  
SSD processes an image in a single  pass, making it faster than RCNN 
models. Howe ver, it is less  accurate  than YOLO, particularly in detecting 
small or dense objects. Its computational complexity also makes it less 
efficient for real -time applications.

def count_people(image_p ath): 
    """ 
 
     Count people in an image with optimized parameters for better detection  
     
    Args:  
        image_path: Path to the image  
    Returns:  
        tuple: (count of people, list of filtered bounding boxes)  
    """ 
    # Load model  
    global model  
    if not isinstance(model, YOLO):  
        model = YOLO('yolov5l.pt')  
     
    # Process image with optimized parameters  
    results = model.predict(  
        source=image_path,  
        conf=0.25,        # Lower confidence threshold  
        iou=0.45,         # Lower IOU threshold for more detections  
        imgsz=1280,       # High resolution  
        classes=[0],      # Only detect person class  
        max_det=100       # Increased maximum detections  
    ) 
     
    people_detections = []  
    bounding_boxes = []  
     
    if len(results) > 0 and len(results[0].boxes) > 0:  
        boxes = results[0].boxes  
         
        # Sort boxes by confidence score  
        box_scores = [(i, float(box.conf)) for i, box in enumerate(boxes)]  
        box_sc ores.sort(key=lambda x: x[1], reverse=True)  
         
        used_areas = []  
         
        for idx, score in box_scores:  
            box = boxes[idx]  
            if int(box.cls) == 0:  # Person class  
                x1, y1, x2, y2 = box.xyxy[0].cpu(). numpy()  
                conf = float(box.conf)  
                 
                # Calculate box dimensions  
                width = x2 - x1 
                height = y2 - y1 
                area = (x2 - x1) * (y2 - y1) 
                aspect_ratio = height /  width if width > 0 else 0  
                 
 
                  # More lenient size criteria  
                is_valid_size = (  
                    aspect_ratio >= 0.5 and      # Allow wider people  
                    aspect_ratio <= 4.0 and      # Allow taller  people  
                    height >= 30 and             # Lower minimum height  
                    width >= 15                  # Lower minimum width  
                ) 
                 
                # Check overlap with existing detections  
                overlap = False  
                for used_box in used_areas:  
                    ux1, uy1, ux2, uy2 = used_box  
                    intersection_x1 = max(x1, ux1)  
                    intersection_y1 = max(y1, uy1)  
                    intersection_x2 = min (x2, ux2)  
                    intersection_y2 = min(y2, uy2)  
                     
                    if intersection_x2 > intersection_x1 and intersection_y2 > intersection_y1:  
                        intersection_area  = (intersection_x2 - intersection_x1) * (intersection_y2 - 
intersection_y1)  
                        overlap_ratio = intersection_area / min(area, (ux2 - ux1) * (uy2 - uy1))  
                        if overlap_ratio > 0.7:  # More lenient overlap threshold  
                            overlap = True  
                            break  
                 
                if is_valid_size and not overlap:  
                    people_detections.append(box)  
                    bounding_boxes.append((x1, y1, x2, y2, con f)) 
                    used_areas.append((x1, y1, x2, y2))  
     
    return len(people_detections), bounding_boxes

def draw_box_plot(frame, count_history, max_history=100):  
    """Draw a box plot of recent people counts at the bottom of the frame"""  
    height, width = frame.shape[:2]  
    
    # Define plot area  
    plot_height = 100  
    plot_y = height - plot_height - 10 
    plot_x = 50  
    plot_width = width - 100 
    
    # Create plot background  
    cv2.rectangle(frame, (plot_x -2, plot_y -2), 
                 (plot_x+pl ot_width+2, plot_y+plot_height+2),  
                 (255, 255, 255), 2)  
    
    # Only keep last max_history points  
    if len(count_history) > max_history:  
        count_history = count_history[ -max_history:]  
    
    if len(count_history) > 0:  
        # Calculate statistics  
        max_count = max(max(count_history), 1)  # Avoid division by zero  
        
        # Draw points  
        for i, count in enumerate(count_history):  
            x = plot_x + int((i / max_history) * plot_width)  
            y = plot_y  + plot_height - int((count / max_count) * plot_height)  
            cv2.circle(frame, (x, y), 2, (0, 255, 0), -1) 
        
        # Draw current count prominently  
        current_count = count_history[ -1] 
        cv2.putText(frame, f'Current Count: { current_count}',  
 
                     (width -300, 50), cv2.FONT_HERSHEY_SIMPLEX,  
                   1, (0, 255, 0), 2)  
        
        # Add y -axis labels  
        cv2.putText(frame, str(max_count), (plot_x -40, plot_y+10),  
                   cv2.FONT_HERSHEY_ SIMPLEX, 0.5, (255, 255, 255), 1)  
        cv2.putText(frame, '0', (plot_x -20, plot_y+plot_height),  
                   cv2.FONT_HERSHEY_SIMPLEX, 0.5, (255, 255, 255), 1)  
    return frame

def process_video(video_path):  
    import cv2  
    from datetime import datetime  
    
    # Load YOLOv5 model  
    global model  
    if not isinstance(model, YOLO):  
        model = YOLO('yolov5l.pt')  
    
    video = cv2.VideoCapture(video_path)  
    fps = video.get(cv2.CAP_PROP_FPS)  
    width = int(video.get(cv2.CAP_PROP_FRAME_WIDTH))  
    height = int(video.get(cv2.C AP_PROP_FRAME_HEIGHT))  
    total_frames = int(video.get(cv2.CAP_PROP_FRAME_COUNT))  
    
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")  
    output_filename = f'counted_{timestamp}_{os.path.basename(video_path)}'  
    output_path = os.path.join( app.config['UPLOAD_FOLDER'], output_filename)  
    
    fourcc = cv2.VideoWriter_fourcc(*'avc1')  
    out = cv2.VideoWriter(output_path, fourcc, fps, (width, height))  
    
    frame_number = 0  
    frame_results = []  
    count_history = []  # Store count histor y for plotting  
 
     
    process_every_n_frames = max(1, int(fps // 2))  
    
    while video.isOpened():  
        ret, frame = video.read()  
        if not ret:  
            break  
            
        frame_number += 1  
        
        if frame_number % process_every_n_frames == 0:  
            # Run detection  
            results = model.predict(source=frame, conf=0.25, imgsz=1280)  
            
            # Count people  
            people_count = len([box for box in results[0].boxes if int(box.cls) == 0])  
            count_history.append(people_count)  
            
            # Store result  
            timestamp_seconds = frame_number / fps  
            minutes = int(timestamp_seconds // 60)  
            seconds = int(timestamp_seconds % 60)  
            frame_ results.append({  
                'frame': frame_number,  
                'timestamp': f'{minutes:02d}:{seconds:02d}',  
                'count': people_count  
            }) 
            
            # Get annotated frame with boxes  
            annotated_frame =  results[0].plot()  
            
            # Add box plot  
            annotated_frame = draw_box_plot(annotated_frame, count_history)  
            
            # Add additional statistics  
            avg_count = sum(count_history) / len(count_history)  
            cv2.putText(annotated_frame,  
                       f'Avg Count: {avg_count:.1f}',  
                       (50, 90), cv2.FONT_HERSHEY_SIMPLEX,  
                       1, (0, 255, 0), 2)  
            
            out.write(annotated_frame)  
        else: 
            # For skipped frames, add box plot to original frame  
            if count_history:  
                frame = draw_box_plot(frame, count_history)  
 
              out.write(frame)  
        
        if frame_number % 100 == 0:  
            print(f"Processed {frame_number}/{total_frames} frames")  
    
    video.release()  
    out.release()  
    web_compatible_path = convert_video_to_web_compatible(output_path)  
    return web_compatible_path, frame_results

societal and technical implications. In smar t cities and security, the project can 
enhance surveillance systems by providing real -time object detection, assisting 
in traffic monitoring, and improving public safety by identifying suspicious 
activities. In healthcare and accessibility, the application  of YOLO -based

care. The industrial and automation sector can benefit from this technolog y by
